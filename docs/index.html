It started with two school surveys

Before writing any code, the developer surveyed middle school students about phone use and mental health.

41%

at moderate-to-severe risk for problematic smartphone use

Study 1: Smartphone use (SABAS)

148 middle school students took the Smartphone Application-Based Addiction Scale. Higher risk went with compulsive phone checking, more time on the phone, less physical activity, and smartphone-related symptoms.

Study 2: Mental health (PHQ-9)

147 middle school students took the Patient Health Questionnaire-9. Beyond the 50.3% above, 13.6% scored in the moderately severe or severe range.

Scientific note. These were observational surveys at one point in time. They do not show that online content caused these results, and they do not show that filtering content changes them. They motivated the project. Only aggregate findings are shown here.

Whole-site blocking is too blunt

Parental controls usually allow or block an entire domain. MindShield AI works on single images and passages of text, so the rest of the page is left alone.

How it works

  1. Pick your filters

    Open the popup and switch on the categories you want. Everything else is left untouched.

  2. Browse normally

    The extension checks supported images and visible text as pages load and as new posts appear.

  3. Stay in control

    Matches are covered with a notice. Tap Show anyway to reveal one, or pause protection for 10 minutes or entirely.

The technology

  • A Chrome extension in JavaScript sends images and text to a Python server running on your own computer.
  • Images are scored with CLIP ViT-B/32 by comparing them with text descriptions of each category. It needs no training examples of its own.
  • Text is scored with an NLI model, nli-MiniLM2-L6-H768, which checks how well a passage fits each category.
  • Scores are ranked against a threshold you tune with the sensitivity setting. They are not calibrated probabilities.

Privacy, stated carefully

  • Analysis runs in a local Python server at 127.0.0.1. This app does not send page content to a hosted AI service, and it needs no account or API key.
  • Model weights download from a model repository the first time you run it.
  • Chrome storage holds your settings and category counts. The app is not designed to save images, page text, URLs or browsing history.
  • This has not been independently audited.

What it gets wrong

  • Detection accuracy has not been formally measured, so no accuracy figures are listed.
  • It misses some harmful content and flags some harmless content, especially educational material.
  • It handles supported images and visible text, not every element or browser.

What comes next

  • Measure accuracy and run a usability study.
  • Make video filtering reliable.
  • Try stronger AI models and work on more websites and streaming platforms.

Why it exists

A student researcher surveyed classmates about smartphone use and mental health. The results did not point toward telling teenagers to use their phones less. They pointed toward giving teenagers more say over what their phones show them.

What if we could use artificial intelligence to make the internet healthier instead of simply telling teenagers to use it less?

Try it yourself

The source is public. It runs from source on a Mac today and is not on the Chrome Web Store.

  1. Download the repository and open the MindShield_AI_Unified/backend folder in Terminal.
  2. Create and activate a Python environment, then run python -m pip install -r requirements.txt -r video_requirements.txt.
  3. Start the page server with python server.py. For YouTube analysis, also run python video_server.py in a second window.
  4. In Chrome, open chrome://extensions, turn on Developer mode, choose Load unpacked, and select the extension folder.
