Privacy center

Images and webpage text are processed by an AI server running on your own computer. They are not sent to a cloud inference provider by this application. On first setup, pretrained model weights download from the model repository. Only category counts and settings are stored in Chrome. The app does not intentionally save images, page text, URLs, or browsing history.

Filtering is experimental and is not a mental-health diagnostic or safety system. Some images may fail to load for analysis, and model predictions can be inaccurate.
